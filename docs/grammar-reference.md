## 1. Ser vs Estar & Adjective Semantic Shifts

### Core Distinction
- **Ser** (*Essential Identity / Inherent Properties / Origin / Time*): Defines what a subject **is**.
- **Estar** (*State / Condition / Location / Progressive Aspect*): Defines how a subject **stands / feels / is situated**.

### Adjectives that Shift Meaning
| Adjective | With *Ser* (Inherent Trait) | With *Estar* (Temporary State) |
| :--- | :--- | :--- |
| **listo** | Clever, smart (*Es muy listo*) | Ready, prepared (*Está listo*) |
| **rico** | Wealthy, affluent (*Es rico*) | Delicious, tasty (*La sopa está rica*) |
| **atento** | Courteous, considerate (*Es atento*) | Paying attention (*Está atento*) |
| **verde** | Green-colored (*Es verde*) | Unripe, immature (*El plátano está verde*) |
| **aburrido**| Boring person/thing (*La clase es aburrida*) | Bored (*Estoy aburrido*) |
| **grave** | Serious, solemn (*Voz grave*) | Critically ill (*El paciente está grave*) |

## 2. Past Aspectual Shifts (*Pretérito vs Imperfecto*)

Certain Spanish verbs alter their inherent lexical meaning depending on whether they are conjugated in the **Pretérito Indefinido** (perfective/punctual) or the **Pretérito Imperfecto** (imperfective/state).

| Verb | Pretérito Indefinido (Punctual / Culmination) | Pretérito Imperfecto (Continuous / Mental State) |
| :--- | :--- | :--- |
| **conocer** | Met for the first time (*La conocí ayer*) | Knew / was acquainted with (*La conocía desde niño*) |
| **saber** | Found out / learned (*Ayer supe la verdad*) | Knew (information) (*Yo ya lo sabía*) |
| **querer** | Tried / attempted to (*Quiso entrar*) | Wanted / felt like (*Quería descansar*) |
| **no querer**| Refused to (*No quiso firmar*) | Did not want to (*No quería molestar*) |
| **poder** | Managed to / succeeded in (*Pude arreglarlo*) | Was capable of / had the ability (*Podía hacerlo*) |
| **no poder**| Failed after trying (*No pude abrir la puerta*) | Was unable to (*No podía asistir*) |

## 3. Subjunctive Triggers (*WEIRDO* & *ESCAPA*)

### The WEIRDO Trigger Framework
Subjunctive is required in subordinate noun clauses when the main clause expresses:
- **W** - *Wishes & Volition*: *Querer que*, *Desear que*, *Exigir que*, *Preferir que*.
- **E** - *Emotion & Evaluation*: *Alegrarse de que*, *Temer que*, *Sentir que*, *Es bueno que*.
- **I** - *Impersonal Expressions*: *Es necesario que*, *Es fundamental que*, *Conviene que*.
- **R** - *Requests & Directives*: *Pedir que*, *Mandar que*, *Recomendar que*, *Sugerir que*.
- **D** - *Doubt & Denial*: *Dudar que*, *No creer que*, *Negar que*, *No pensar que*.
- **O** - *Ojalá*: *¡Ojalá (que) tengamos éxito!*

### Adverbial Clauses of Time & Condition (*ESCAPA*)
Always trigger the subjunctive:
- **E** - *En caso de que* (in case that)
- **S** - *Sin que* (without)
- **C** - *Con tal de que* (provided that)
- **A** - *Antes de que* (before)
- **P** - *Para que* / *A fin de que* (so that / in order that)
- **A** - *A menos que* / *A no ser que* (unless)

## 4. Por vs Para (Motive vs Purpose)

### Rules for *Por* (Cause, Exchange & Path)
1. **Cause / Motive / Reason**: *Lo hice por ti* (Because of you).
2. **Exchange / Cost**: *Pagué 20 euros por el libro*.
3. **Transit / Trajectory**: *Paseamos por el parque*.
4. **Duration / Approximate Time**: *Trabajó por dos horas*.
5. **Means of Transportation / Communication**: *Te envié el código por correo*.
6. **Passive Voice Agent**: *El bug fue corregido por el equipo*.
7. **Multiplication / Percentages**: *Tres por cinco; el diez por ciento*.

### Rules for *Para* (Destination & Purpose)
1. **Purpose / Goal (+ Infinitive)**: *Estudio para aprender*.
2. **Recipient**: *Este pull request es para ti*.
3. **Deadline / Target Date**: *La entrega es para el viernes*.
4. **Physical Destination**: *Salgo para Madrid*.
5. **Opinion / Personal Assessment**: *Para mí, la arquitectura es sólida*.
6. **Standard of Comparison**: *Para ser junior, programa muy bien*.

## 5. Clitic Pronoun Stacking & Accentuation

### Rule 1: Indirect Object Precedes Direct Object
When both pronouns appear together, the sequence is always:
$$\text{Indirect Object (me, te, le, nos, os, les)} + \text{Direct Object (lo, la, los, las)}$$

### Rule 2: The *Le/Les* $\rightarrow$ *Se* Conversion
When a third-person indirect pronoun (*le/les*) is followed by a third-person direct pronoun (*lo/la/los/las*), the indirect pronoun obligatorily converts to **se**:
- *Le doy el libro* $\rightarrow$ *\*Le lo doy* (Incorrect) $\rightarrow$ **Se lo doy** (Correct).

### Rule 3: Clitic Attachment & Written Accents
When attaching two pronouns to an infinitive, gerund, or affirmative imperative, add an accent mark to maintain natural syllable stress:
- *Decir + le + lo* $\rightarrow$ **Decírselo**
- *Entregando + me + lo* $\rightarrow$ **Entregándomelo**
- *Da + me + lo* $\rightarrow$ **Dámelo**

## 6. Prepositional Regimes (*Regímenes Preposicionales*)

Certain verbs obligatorily govern specific bound prepositions:

| Verb + Preposition | Meaning | Example |
| :--- | :--- | :--- |
| **acordarse de** | To remember | *Me acordé de tu sugerencia.* |
| **soñar con** | To dream about | *Sueña con fundar su propia startup.* |
| **pensar en** | To think about | *Pienso en optimizar la consulta SQL.* |
| **insistir en** | To insist upon | *Insistió en realizar una prueba de carga.* |
| **fijarse en** | To pay attention to | *Fíjate en los logs de error.* |
| **negarse a** | To refuse to | *Se negó a desplegar en viernes.* |
| **consistir en** | To consist of | *El plan consiste en migrar a Kubernetes.* |

## 7. Accidental & Involuntary *Se*

Expresses unintentional actions, accidents, or memory slips without direct blame:

$$\textbf{Se} + \text{Indirect Object (Victim)} + \text{Verb (Agrees with Object)} + \text{Subject (Object)}$$

- *Se me cayó la base de datos* (The database crashed on me / I dropped the database).
- *Se nos olvidaron las credenciales* (We forgot the credentials).
- *Se le rompieron las pruebas* (The tests broke on him/her).

## 8. False Friends & High-Frequency Traps

| Spanish False Friend | Real Meaning | True Translation for English Word |
| :--- | :--- | :--- |
| **actualmente** | Currently / Nowadays | Actually $\rightarrow$ *en realidad, de hecho* |
| **eventualmente** | Occasionally / Uncertainly | Eventually $\rightarrow$ *con el tiempo, tarde o temprano* |
| **pretender** | To aim / intend / attempt | To pretend $\rightarrow$ *fingir* |
| **realizar** | To execute / carry out / achieve | To realize $\rightarrow$ *darse cuenta de* |
| **soportar** | To tolerate / endure / put up with | To support (code/infrastructure) $\rightarrow$ *admitir, ser compatible con, respaldar* |
| **sensato** | Wise / level-headed / reasonable | Sensitive $\rightarrow$ *sensible* |
