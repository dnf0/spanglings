# Verbal Periphrasis: Ponerse a + Infinitive
<!-- id: c1_periphrasis_ponerse | level: C1 | topic: verbal_periphrases | type: cloze -->

> **Grammar Rule**: The periphrasis 'ponerse a + infinitive' describes the sudden or decisive start of an action.

### Context
English: "It suddenly started raining."

### Exercise
Se puso ___ llover repentinamente.

<!-- SOLUTION
a
