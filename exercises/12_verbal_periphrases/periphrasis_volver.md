# Verbal Periphrasis: Volver a + Infinitive
<!-- id: c1_periphrasis_volver | level: C1 | topic: verbal_periphrases | type: cloze -->

> **Grammar Rule**: The periphrasis 'volver a + infinitive' expresses that an action is repeated (doing something again).

### Context
English: "I will write the letter again."

### Exercise
Volveré ___ escribir la carta.

<!-- SOLUTION
a
