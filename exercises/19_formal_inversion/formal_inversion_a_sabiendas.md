# Absolute Clause: A sabiendas de que
<!-- id: c1_formal_inversion_a_sabiendas | level: C1 | topic: formal_inversion | type: cloze -->

> **Grammar Rule**: 'A sabiendas de que' (fully knowing that) is a formal absolute structure that must be followed by the indicative.

### Context
English: "He did it fully knowing that it was forbidden."

### Exercise
Lo hizo a sabiendas de que (estar) ___ prohibido.

<!-- SOLUTION
estaba
