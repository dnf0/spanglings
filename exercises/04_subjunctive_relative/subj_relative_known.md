# Subjunctive: Known Antecedent
<!-- id: b2_subj_relative_known | level: B2 | topic: subjunctive_relative | type: cloze -->

> **Grammar Rule**: If the antecedent in the relative clause is a specific, known, or existing entity, use the indicative.

### Context
English: "I am looking for the book (specific one) that has the map."

### Exercise
Busco el libro que (tener) ___ el mapa.

<!-- SOLUTION
tiene
-->
