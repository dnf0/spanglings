# Conditional Clauses: Si + Imperfect Subjunctive
<!-- id: b2_imp_subj_cond_si_claus | level: B2 | topic: imperfect_subjunctive_conditionals | type: cloze -->

> **Grammar Rule**: Contrary-to-fact conditional clauses starting with 'si' (if) must use the imperfect subjunctive, while the main clause uses the conditional.

### Context
English: "If I had money, I would travel around the world."

### Exercise
Si yo (tener) ___ dinero, viajaría por el mundo.

<!-- SOLUTION
tuviera
-->

<!-- ALTERNATIVES
tuviese
-->
