# Conditional Sentences: Main Clause
<!-- id: b2_imp_subj_cond_main_clause | level: B2 | topic: imperfect_subjunctive_conditionals | type: cloze -->

> **Grammar Rule**: Contrary-to-fact conditional sentences use the imperfect subjunctive in the 'si' clause, and the conditional tense in the main clause.

### Context
English: "If we lived in Spain, we would eat paella every day."

### Exercise
Si viviéramos en España, nosotros (comer) ___ paella todos los días.

<!-- SOLUTION
comeríamos
-->
