# Subjunctive: Como si
<!-- id: b2_imp_subj_cond_como_si | level: B2 | topic: imperfect_subjunctive_conditionals | type: cloze -->

> **Grammar Rule**: 'Como si' (as if) always triggers the imperfect subjunctive.

### Context
English: "He talks as if he were the boss."

### Exercise
Habla como si (ser) ___ el jefe.

<!-- SOLUTION
fuera
-->

<!-- ALTERNATIVES
fuese
-->
