# Conditional Perfect: Main Clause
<!-- id: c1_pluperfect_subj_conditional_perfect | level: C1 | topic: pluperfect_subjunctive | type: cloze -->

> **Grammar Rule**: The main clause of past contrary-to-fact conditional sentences uses the conditional perfect (habría + past participle).

### Context
English: "If we had run, we would have caught the train."

### Exercise
Si hubiéramos corrido, nosotros ___ alcanzado el tren.

<!-- SOLUTION
habríamos
-->
