# Rioplatense Production Voseo 04: Decommissioning Infrastructure

> **Grammar & Lexicon**: Decommissioning, turning off, or deprecating a cluster node or legacy service is standardly expressed as **dar de baja**. In Rioplatense voseo imperative, *dar* becomes *dale* or *da*: *dá de baja*.

### Context
English: "Decommission the legacy database instance once the read replicas have fully synchronized."

### Exercise
Una vez que las réplicas de lectura estén sincronizadas, (dá de baja la instancia / da de baja la instancia) ___ heredada de base de datos.

<!-- SOLUTION
da de baja la instancia
-->

<!-- ALTERNATIVES
dá de baja la instancia
