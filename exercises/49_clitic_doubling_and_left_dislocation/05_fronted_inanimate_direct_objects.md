# Clitic Doubling 05: Left-Dislocated Inanimate Direct Objects
<!-- id: b2_clitic_fronted_accusative_inanimate | level: B2 | topic: clitic_doubling_and_left_dislocation | type: cloze | concepts: ["clitic_doubling_fronted_accusative"] | prerequisites: ["clitic_doubling_mandatory_dative", "clitic_pronoun_stacking"] | grammar_focus: "Accusative clitic resumption with topicalized inanimate direct objects." | contrast_note: "Mandatory clitic resumption (*Este informe técnico lo redacté*) vs omission." -->

> **Grammar Rule**: When a specific, definite inanimate direct object is placed before the verb for topical emphasis, standard Spanish requires clitic resumption with *lo/la/los/las*.

### Context
English: "This technical report I wrote over the weekend for the board of directors."

### Exercise
(Este informe técnico lo redacté / Este informe técnico redacté) ___ durante el fin de semana para la junta directiva.

<!-- SOLUTION
Este informe técnico lo redacté
