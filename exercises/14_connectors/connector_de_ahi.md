# Connector: De ahí que
<!-- id: c1_connector_de_ahi | level: C1 | topic: connectors | type: cloze -->

> **Grammar Rule**: 'De ahí que' (hence / that is why) always triggers the subjunctive. If the context is in the past, use the imperfect subjunctive.

### Context
English: "He didn't study, hence he failed the exam."

### Exercise
No estudió, de ahí que (reprobar) ___ el examen.

<!-- SOLUTION
reprobara
-->

<!-- ALTERNATIVES
reprobase
-->
