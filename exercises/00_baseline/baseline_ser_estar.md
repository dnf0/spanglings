# Ser vs Estar Basics: Cold Soup
<!-- id: baseline_ser_estar | level: Baseline | topic: baseline | type: cloze -->

> **Grammar Rule**: Use 'estar' for temporary states like temperature or location, while 'ser' is used for permanent characteristics or identity.

### Context
English: "The soup is cold right now."

### Exercise
La sopa (estar) ___ fría en este momento.

<!-- SOLUTION
está
