# Irregular Preterite Stem: Poner
<!-- id: baseline_preterite_puse | level: Baseline | topic: baseline | type: cloze -->

> **Grammar Rule**: Poner (to put) has an irregular preterite stem 'pus-' with the 'yo' form ending in '-e': 'puse'.

### Context
English: "Yesterday I put the keys on the table."

### Exercise
Ayer yo (poner) ___ las llaves sobre la mesa.

<!-- SOLUTION
puse
