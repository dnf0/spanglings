# Indirect vs Direct Pronouns: Giving the Book
<!-- id: baseline_direct_indirect | level: Baseline | topic: baseline | type: cloze -->

> **Grammar Rule**: When direct and indirect object pronouns are used together, the indirect pronoun comes first (IOP + DOP). If the indirect pronoun is 3rd person (le/les), it changes to 'se' before 'lo/la/los/las'.

### Context
English: "I gave the book to Juan. I gave it to him yesterday."

### Exercise
Le di el libro a Juan. Se (lo) ___ di ayer.

<!-- SOLUTION
lo
