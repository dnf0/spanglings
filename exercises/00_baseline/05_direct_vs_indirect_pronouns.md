# Baseline 05: Direct vs Indirect Object Contrast
<!-- id: b0_direct_vs_indirect_01 | level: Baseline | topic: pronouns | type: cloze | concepts: ["direct_indirect_pronouns"] | prerequisites: [] | grammar_focus: "Direct object (accusative) vs indirect object (dative) pronouns." | contrast_note: "Contrast lo/la direct object with le/les indirect object." -->

> **Grammar Rule**: Direct object pronouns replace what/who receives action directly (lo/la/los/las). Indirect object pronouns indicate to/for whom action is performed (le/les).

### Context
English: "I saw the movie yesterday and I really liked it (I saw it)."

### Exercise
La película era fantástica; ayer ___ vi en el cine.

<!-- SOLUTION
la
-->

<!-- ALTERNATIVES
la vi
-->
