# Passive Refleja: Singular Object
<!-- id: c1_passive_refleja_vende | level: C1 | topic: passive_refleja | type: cloze -->

> **Grammar Rule**: In passive 'se' with inanimate objects, the verb must agree in number with the singular noun.

### Context
English: "Bread is sold here."

### Exercise
Aquí se (vender) ___ pan.

<!-- SOLUTION
vende
-->
