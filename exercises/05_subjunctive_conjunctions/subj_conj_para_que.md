# Subjunctive: Para que
<!-- id: b2_subj_conj_para_que | level: B2 | topic: subjunctive_conjunctions | type: cloze -->

> **Grammar Rule**: 'Para que' (so that / in order that) always triggers the subjunctive.

### Context
English: "I bought this so that you can read it."

### Exercise
Compré esto para que lo (leer) ___ tú.

<!-- SOLUTION
leas
-->
