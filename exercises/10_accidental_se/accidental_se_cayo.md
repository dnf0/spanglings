# Accidental Se: Dropping Something
<!-- id: b2_accidental_se_cayo | level: B2 | topic: accidental_se | type: cloze -->

> **Grammar Rule**: The accidental 'se' construction uses 'se' + indirect object pronoun (victim) + verb (conjugated to match the object that was dropped/lost).

### Context
English: "I dropped the glass (accidentally)."

### Exercise
Se ___ cayó el vaso.

<!-- SOLUTION
me
