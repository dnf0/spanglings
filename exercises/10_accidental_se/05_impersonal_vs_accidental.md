# Accidental Se 05: Passive Se vs Impersonal Se
<!-- id: b2_accidental_se_impersonal | level: B2 | topic: accidental_se | type: cloze -->

> **Grammar Rule**: In accidental 'se', an indirect pronoun (me/te/le/nos/les) is obligatory to identify the affected person.

### Context
English: "His time ran out during the exam."

### Exercise
Durante el examen final, a Juan se ___ (acabar) el tiempo.

<!-- SOLUTION
le acabó
-->

<!-- ALTERNATIVES
le acabo
-->

<!-- DIAGNOSTIC_RULES
pattern: "se acabó" | code: "E1001" | message: "Must include the indirect object pronoun 'le' for Juan -> 'se le acabó'."
-->

<!-- HINTS

Tier 2: 'le acabó'.
Tier 3: The answer is 'le acabó'.
