# Passive Ser vs State Estar
<!-- id: b1_ser_estar_passive_state | level: B1 | topic: ser_vs_estar | type: cloze -->

> **Grammar Rule**: The passive voice uses 'ser' + past participle to indicate an action. The resulting state uses 'estar' + past participle.

### Context
English: "The door was closed (already in that state) when I arrived."

### Exercise
La puerta (estar) ___ cerrada cuando llegué.

<!-- SOLUTION
estaba
-->
