# Ser vs Estar 05: Passive Action (Ser) vs Resultant State (Estar)
<!-- id: b1_ser_estar_passive_state | level: B1 | topic: ser_vs_estar | type: cloze -->

> **Grammar Rule**: 'Ser + participio' forms the passive voice for actions (by an agent). 'Estar + participio' describes the resultant state resulting from a prior action.

### Context
English: "When we arrived, the museum door was already closed."

### Exercise
Cuando llegamos, la puerta del museo ya (estar) ___ cerrada.

<!-- SOLUTION
estaba
-->

<!-- ALTERNATIVES
estaba cerrada
estuvo
-->

<!-- DIAGNOSTIC_RULES
