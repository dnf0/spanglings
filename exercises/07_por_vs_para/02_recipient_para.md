# Por vs Para 02: Intended Recipient (Para)
<!-- id: b1_por_para_recipient | level: B1 | topic: por_vs_para | type: cloze -->

> **Grammar Rule**: Use 'para' to indicate the intended recipient or destination of an object or gift.

### Context
English: "This birthday gift is for you."

### Exercise
Este regalo de cumpleaños es ___ ti.

<!-- SOLUTION
para
-->

<!-- ALTERNATIVES
para
-->
