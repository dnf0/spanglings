# Por vs Para: Exchange
<!-- id: b1_por_para_exchange | level: B1 | topic: por_vs_para | type: cloze -->

> **Grammar Rule**: 'Por' is used to express cost, exchange, trade, or substitution.

### Context
English: "I bought this shirt for twenty dollars."

### Exercise
Compré esta camisa ___ veinte dólares.

<!-- SOLUTION
por
-->
