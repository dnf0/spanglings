# Por vs Para: Recipient
<!-- id: b1_por_para_recipient | level: B1 | topic: por_vs_para | type: cloze -->

> **Grammar Rule**: 'Para' is used to specify the intended recipient of an object or an action.

### Context
English: "This gift is for you."

### Exercise
Este regalo es ___ ti.

<!-- SOLUTION
para
-->
