# Por vs Para: Purpose
<!-- id: b1_por_para_purpose | level: B1 | topic: por_vs_para | type: cloze -->

> **Grammar Rule**: 'Para' is used to express purpose, objective, or goal (in order to).

### Context
English: "I study in order to get a good job."

### Exercise
Estudio ___ conseguir un buen trabajo.

<!-- SOLUTION
para
