# Por vs Para: Cause
<!-- id: b1_por_para_cause | level: B1 | topic: por_vs_para | type: cloze -->

> **Grammar Rule**: 'Por' is used to express cause, reason, or motive (because of, on behalf of).

### Context
English: "We did not go to the beach because of the rain."

### Exercise
No fuimos a la playa ___ la lluvia.

<!-- SOLUTION
por
-->
