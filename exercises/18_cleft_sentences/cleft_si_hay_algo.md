# Cleft Sentences: Si hay algo que...
<!-- id: c1_cleft_si_hay_algo | level: C1 | topic: cleft_sentences | type: transformation -->

> **Grammar Rule**: In cleft structures, the copula 'ser' must agree in number with the focused element that follows it.

### Context
English: "If there is something that bothers me, it is (plural) lies."

### Exercise
Si hay algo que me molesta, ___ las mentiras.

<!-- SOLUTION
son
