# Cleft Sentences: Fue entonces cuando
<!-- id: c1_cleft_entonces | level: C1 | topic: cleft_sentences | type: transformation -->

> **Grammar Rule**: In cleft sentences focusing on time, the adverb 'cuando' must accompany the temporal focus (e.g., 'Fue entonces cuando...').

### Context
English: "It was then when I understood everything."

### Exercise
Fue entonces ___ comprendí todo.

<!-- SOLUTION
cuando
-->
